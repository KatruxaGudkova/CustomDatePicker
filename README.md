# Инструкция по установке и запуску проекта Custom-Date-Picker

## 1. Клонировать репозиторий

```
git clone https://github.com/KatruxaGudkova/CustomDatePicker.git
cd date-picker-app
```

## 2. Установить зависимости

```
npm install
```

## 3. Запустить проект

```
npm start
```

Приложение откроется по адресу [http://localhost:3000](http://localhost:3000)

## 4. Сборка проекта

```
npm run build
```
